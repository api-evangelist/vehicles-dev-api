# Vehicles.dev API

A multi-product REST/JSON API providing vehicle data (VIN decoding, market valuation, listings, depreciation, recalls, specifications, ownership costs) and employment/labor-market data, with a control plane for account, API-key, and billing management. Secured via product API keys and WorkOS tokens; publicly described by an OpenAPI 3.1 contract.
